# hxyfront-62011 马术蹄铁修整档案 · 蹄铁翻新复用与装蹄排他闭环

源提示词编号：6

在原有修蹄记录（马匹编号、步态问题、蹄形评估、蹄铁类型、钉位、修蹄/复查日期、左右前后蹄对比、异常步态标记、更换历史）之上，扩展为蹄铁翻新复用与装蹄排他闭环。

## 闭环规则

1. **装蹄排他**：同一片蹄铁在拆下之前不得装给第二匹马；蹄铁状态为“在装 / 待拆”时排他占用。
2. **翻新登记**：拆下的蹄铁登记磨耗量（mm）、锻修温度（℃）、钉孔状态；磨耗 > 4 mm 或钉孔“扩孔”只能报废归档（终态，不可再装）。合格件进入“翻新待匹配”库。
3. **匹配复用**：翻新件必须与目标蹄位的蹄形、规格同时匹配才能装蹄；不符则退回“待匹配”库。新件按规格直装。
4. **一蹄位一有效记录**：装蹄后同一蹄位只保留一条有效（未关闭）记录；同一请求并发双发时第二次沿用首次记录，不产生第二条。
5. **复查失效留档**：复查不合格时蹄铁停在“待拆”，原装蹄结论改为“已失效”但记录保留；拆除前该蹄位与蹄铁均拒绝新装蹄。拆除后记录关闭归档，蹄位释放，蹄铁进入翻新判定。
6. **履历与一致性**：蹄铁入库、装蹄、复查、拆除、翻新、匹配通过/退回、报废全部写入只追加履历；刷新后以有效装蹄记录重建排他占用，页脚提供占用 × 状态 × 履历一致性体检。

## 三层分离

- `src/domain/`（判断层）：`types.ts` 数据模型、`rules.ts` 纯判定与选择器、`engine.ts` 命令状态机、`seed.ts` 演示数据（全部由命令生成，天然自洽）。
- `src/storage/archiveStore.ts`（存储层）：localStorage 读写、损坏回落、重置；不含业务规则。
- `src/ui/`（界面层）：马匹档案、装蹄排他工作台、蹄铁库房/翻新、复查与留档四个面板；界面只发送命令，不直接改状态。

## 技术栈

React 19 + Vite + TypeScript（本地状态 + localStorage，无后端）

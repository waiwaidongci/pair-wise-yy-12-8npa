# hxyfront-62011 马术蹄铁档案 · 翻新复用与装蹄排他闭环

源提示词编号：6

面向马术俱乐部蹄铁师的修蹄记录前端：马匹档案、蹄形评估、左右前后蹄对比、异常步态标记、复查提醒，并在其上实现**蹄铁翻新复用**与**装蹄排他闭环**。

## 闭环规则

1. **装蹄排他**：同一蹄铁未拆下前（装蹄中 / 待拆）不得装给第二匹马。
2. **一蹄位一有效记录**：同一马蹄同一蹄位只留一条有效装蹄记录；第二次（并发）装蹄直接沿用首次，不新开占用。
3. **翻新登记**：拆下后登记本次磨耗量、锻修温度、钉孔状态与成型蹄形。磨耗超单次上限（4mm）或钉孔扩孔 / 裂纹，只能**报废归档**；合格件回待匹配池成为翻新件。
4. **匹配装蹄**：翻新件（及新件）必须与目标蹄的蹄形、规格、蹄位三者匹配才能装蹄；不符自动**退回待匹配**并留履历。
5. **复查闭环**：复查合格继续装蹄；不合格时蹄铁**停在待拆**，原结论标记失效留档，占用不解除，必须拆下后才能翻新。
6. **履历留痕**：装蹄、沿用、拆下、复查、翻新合格、报废、退回全部追加为不可变事件，按蹄铁聚合为完整履历。
7. **刷新一致**：界面状态全部由档案重建；读取 / 写入均做一致性审计（蹄位有效记录唯一、蹄铁占用状态与装蹄记录一一对应），异常时回退种子档案。

## 分层架构（判断 / 存储 / 界面分开）

| 层 | 位置 | 职责 |
| --- | --- | --- |
| 判断层 | `src/domain/` | 纯 TS：`types.ts` 数据模型、`rules.ts` 业务规则与审计（不依赖 React / localStorage）、`seed.ts` 演示档案 |
| 存储层 | `src/storage/archive-store.ts` | localStorage 持久化、刷新恢复、落盘前一致性校验 |
| 状态编排 | `src/state/useArchive.ts` | 把界面命令交给纯规则函数，再校验、落盘、刷新界面 |
| 界面层 | `src/components/`、`src/App.tsx` | 马匹蹄位占用、蹄铁台账、翻新登记、履历事件流 |

## 本地运行

```bash
npm install
npm run dev        # 开发端口 62011
npm run typecheck  # 类型检查
npm run test:rules # 领域规则闭环测试（12 项）
npm run build      # 类型检查 + 生产构建
```

技术栈：React 19 + Vite + TypeScript，无后端，数据保存在浏览器 localStorage。
